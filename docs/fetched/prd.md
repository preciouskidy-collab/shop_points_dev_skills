# M7W2【触达】积分过期提醒

> 文档版本：v1.5 创建日期：2026-07-13 最后更新：2026-07-15 所属模块：门店积分系统 - 运营触达



---

## 一、场景说明

积分统一在每月最后一天24:00过期，门店对过期无感知，将导致积分浪费、体验差、积分价值感降低。

**目标**：在积分过期前主动提醒门店，提升积分兑换率和积分价值感知。

### 2.3 触发流程

```Plain Text
每日 8:00
  → 判断今日是否为触发日（15号/倒数3天/最后1天）
    → 否：不执行
    → 是：
      → 查询当月即将过期积分的门店列表
      → 按品牌匹配触达角色：
          - 贝联：店东 + 公司合伙人 + 财务负责人
          - 链家：商圈经理
      → 查询各角色人员信息（ucid）
      → 【关键】按ucid聚合：同一人关联多个门店时，合并为一条IM/Push消息
      → 组装触达内容
      → 推送给触达平台：
          - IM（人维度，主键ucid）
          - Push（人维度，主键ucid）
      → 记录发送日志
```

## 三、触达内容



### 3.1 标题规则

所有渠道统一标题格式：

```Plain Text
⏰ 门店积分过期倒计时{x}天
```

其中 `{x}` = 距过期的剩余天数，向上取整。月末最后一天当天x=1

### 3.2 文案模板



#### 3.2.1 单门店文案（IM / Push）

**Push 文案**：

```Plain Text
⏰ 门店积分过期倒计时{x}天
{门店名称}有{过期积分数}积分即将过期，前往积分商城兑换 →
```

**IM 文案**：

```Plain Text
⏰ 门店积分过期倒计时{x}天

您管理的{门店名称}有{过期积分数}积分将于{过期日期}过期，请尽快兑换哦～

👉 点击前往门店积分商城 {商城链接}
```



#### 3.2.2 一人多店汇总文案（仅IM / Push）

**背景**：存在一个人管理多个门店的情况，IM和Push是人维度触达（主键ucid），需将多门店信息汇总为一条消息。

**汇总逻辑**：

1. 按ucid聚合该人关联的所有即将过期积分的门店
2. 计算总过期积分数 = 各门店过期积分之和
3. 剩余天数x统一（同一天触达，过期日相同）

**Push 文案（一人多店）**：

```Plain Text
⏰ 门店积分过期倒计时{x}天
你管理的{N}家门店共{总过期积分数}积分即将过期，前往积分商城兑换 →
```

**IM 文案（一人多店）**：

```Plain Text
⏰ 门店积分过期倒计时{x}天

你管理的{N}家门店即将过期积分共计 {总过期积分数}将于{过期日期}过期，请尽快兑换哦～

📋 门店即将过期积分明细：
1. {门店A}：{过期积分数A}积分；
2. {门店B}：{过期积分数B}积分；
3. {门店C}：{过期积分数C}积分（最多展示3个，超出折叠为"等{N}家门店"）

👉 点击前往门店积分商城 {商城链接}
```

> **判断条件**：当ucid关联的门店数 > 1时，使用一人多店文案模板；否则使用单门店模板。

### 6.3 与触达平台的对接方式

**积分系统侧**：

1. 定时任务计算触发日、人群、文案变量
2. 按ucid聚合一人多店数据
3. 组装人维度触达事件（IM + Push）：主键=ucid，携带汇总/单店文案变量
4. 调用触达平台发送接口
5. 事件格式：`scene_id + target_list(content_variables) + channels`

**触达平台侧**：

1. 按渠道发送（IM/Push按ucid）
2. 统一频控
3. 数据回流
